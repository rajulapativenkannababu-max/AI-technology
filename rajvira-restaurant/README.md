# Rajvira Restaurant

A responsive luxury-inspired multi-cuisine restaurant landing page built with HTML and CSS.

## Features
- Responsive navigation and hero section
- Signature dishes and menu cards
- Special offer banner
- Customer testimonials
- Opening hours and contact/location section
- Local SVG artwork in `images/`

## Run locally
Open `index.html` in your browser. No build tools or dependencies are required.

## Customize
Update the restaurant details, menu prices, phone number, address, and email in `index.html`. Replace the SVG files in `images/` with your own photographs if desired.

## Deploy
Push this folder to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main / root**.
